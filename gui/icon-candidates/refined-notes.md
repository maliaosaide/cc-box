# 第二轮精细图标候选

这轮只做两个方向，目标是更像正式产品 Logo，而不是功能元素拼贴。

## refined-01-cc-cube

母题：双 `C` 环绕一个核心盒子。

- `C`：对应 CC-Box，也形成同步回路。
- 盒子：对应配置工具箱、快照对象和可迁移资产。
- 颜色：深蓝绿 + 青色，偏可靠、工程工具、跨平台。
- 小尺寸策略：保留双环和盒子三面结构，减少锁和文字等细碎元素。

文件：

- `refined-01-cc-cube/app.svg`
- `refined-01-cc-cube/tray.svg`
- `refined-01-cc-cube/mono.svg`
- `refined-01-cc-cube/small-16.svg`

## refined-02-core-capsule

母题：配置核心胶囊。

- 胶囊：代表安全容器和可迁移的 Claude 配置核心。
- 三条内层线：代表配置、快照、二进制/项目配置等分层能力。
- 外圈：代表多设备同步和版本回路。
- 颜色：深紫蓝 + 金色/青色点缀，偏现代、专业、AI 工具感。

文件：

- `refined-02-core-capsule/app.svg`
- `refined-02-core-capsule/tray.svg`
- `refined-02-core-capsule/mono.svg`
- `refined-02-core-capsule/small-16.svg`
